# DAM: páginas de privacidad

Páginas públicas de privacidad y de eliminación de cuenta de la app DAM, una carpeta por academia (`salsa-del-barrio/`). La política de privacidad de Salsa del Barrio está en [salsa-del-barrio/privacidad.html](salsa-del-barrio/privacidad.html) (English: [privacy.html](salsa-del-barrio/privacy.html)); la eliminación de cuenta, en [eliminar-cuenta.html](salsa-del-barrio/eliminar-cuenta.html) ([delete-account.html](salsa-del-barrio/delete-account.html)). Sitio estático, sin scripts ni recursos externos.
